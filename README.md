# Free Serp
A free, light, and simple Serp API using JSON for responses, Python for server side compute, Worked for runtime, and JS for clients (with inline HTML capabilities and usability in TS) using Microsoft Bing

## Deploy

As stated, this projects is intended for the worked runtime due to its low compute cost. you can deploy this project to Cloudflare Workers using the button below

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/sriail/Free-Serp-Api)

Or use these commands (Requires Node JS, the NPM Package Manager, Git, and the wrangler / Cloudflare cli Package) Works on Windows, MacOS, And Linux.
```shell
# Install Wrangler (If not already installed)
npm install --save-dev wrangler

# Clone / Prep the repository
git clone https://github.com/sriail/Free-Serp-Api.git
cd Free-Serp-Api

# Install and Deploy
npm install
npx wrangler deploy
```
